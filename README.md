"# imi-web-intro" 
Учебный проект для ТЗ №0 «Введение в современную веб-разработку» (ИМИ СВФУ, 3 курс).
Одностраничное приложение на чистых HTML, CSS и JavaScript: делает GET-запрос через
`fetch` к открытому API и выводит список пользователей карточками.

Во время запроса показывается «Загрузка…». Сетевые ошибки и неуспешные HTTP-ответы
(проверка `response.ok`) обрабатываются: выводится понятное сообщение и кнопка «Повторить».

## API

- GET https://jsonplaceholder.typicode.com/users — 10 тестовых пользователей, JSON, без ключа.

## Запуск

Нужен локальный HTTP-сервер (просто открыть файл двойным кликом нельзя).

**Вариант 1 — VS Code + Live Server:**
1. Установить расширение Live Server (автор Ritwick Dey).
2. Открыть папку проекта, правый клик по `index.html` → Open with Live Server.
3. Откроется http://127.0.0.1:5500
